# Ursala Lindsey: Portfolio

Personal portfolio for Ursala Lindsey, front-end developer and technical support specialist.

Plain HTML, CSS, and JavaScript with no build step. Open `index.html` in a browser to view it, or publish with GitHub Pages.

- `index.html`: page content
- `styles.css`: layout, light and dark themes
- `scripts.js`: hero ticket animation and footer year
- `old-site-2022/`: the previous Bootstrap version
